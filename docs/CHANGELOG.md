# 변경 내역

## 0.1.0-alpha.10 · 2026-11-12

- 한글 용어 입력 직후 Enter가 무시되거나 줄바꿈이 되는 처리를 수정했습니다. 정확한 용어·별칭은 Tab 선택 없이 공유합니다.
- 조합 중 Enter는 최종 글자 확정 후 한 번만 전송합니다. 조합 종료 직후의 Enter도 요청을 유지하고 최종 입력이 반영되기를 기다립니다.
- 전송 Enter가 만든 불필요한 줄바꿈만 beforeinput에서 차단합니다. 한글 조합 문자와 Shift+Enter는 유지합니다.
- 추가 입력·붙여넣기·목록 선택·새 조합·포커스 이동·입력창 교체·종료 때 대기 전송을 취소합니다.
- 합성 IME 이벤트 순서와 실제 ProseMirror 상태 변경 회귀 검사 7개를 추가했습니다. 자동 테스트는 57개입니다.

## 0.1.0-alpha.9 · 2026-11-02

- GitHub 배포용 패키지에는 `Trainrobbery/term-share`의 저장소·고정 manifest·버전별 ZIP 주소를 추가했습니다. 실제 게시와 공개 전환 절차는 `GITHUB-RELEASE.md`에 있습니다.

- 현재 선택된 자동완성 항목의 오른쪽에 `TAP`을 흐리게 표시합니다. 선택 상태를 따라 표시하고 긴 내용과 겹치지 않도록 공간을 확보합니다.
- 새 공유 문구를 `플레이어명님이 다음 지식을 공유했습니다.`로 변경했습니다. 영어 문구도 과거형으로 수정했습니다.
- 기존 자동 테스트 50개를 통과했습니다. TAP의 실제 브라우저 화면 표시는 수동 확인 항목입니다.

## 0.1.0-alpha.8 · 2026-11-02

- 새 공유 안내에서 사용자명 양옆의 대괄호를 제거했습니다. `플레이어명님이 다음 지식을 공유합니다.`로 표시합니다.
- 한국어·영어 문구와 기존 자동 검사 기대값을 수정했습니다. 자동 테스트 50개를 통과했습니다.

## 0.1.0-alpha.7 · 2026-11-02

- 작은 공유 안내를 박스 안쪽, 제목 바로 위로 옮겼습니다. 제목과 같은 좌우 여백을 적용합니다.
- alpha.6에서 이미 공유한 카드도 다시 표시할 때 기존 안내 노드를 박스 안으로 옮깁니다. 저장된 HTML과 기본 채팅 DOM은 보존합니다.
- 기존 표시 검사를 새 위치와 이전 카드의 안내 이동·반복 적용·링크 보존 확인에 맞게 수정했습니다. 자동 테스트 50개를 통과했습니다.

## 0.1.0-alpha.6 · 2026-11-02

- 새 용어 블록 위에 `[플레이어명]님이 다음 지식을 공유합니다.` 안내를 11px 글씨로 표시합니다.
- 공유 시점의 실제 사용자명을 안전하게 이스케이프해 본문에 저장합니다. 안내는 블록 테두리 바깥에 표시합니다.
- 기본 채팅 DOM 보존과 이전 카드의 표시 동작을 유지합니다.
- 기존 카드·렌더링 검사에 안내 위치·문구·크기·표시 여부와 이름 이스케이프 확인을 반영했습니다. 자동 테스트 50개를 통과했습니다.

## 0.1.0-alpha.5 · 2026-11-02

채팅 표시 과정에서 기본 DOM을 삭제하던 처리를 수정했습니다.

- alpha.4의 헤더·시간·버튼 및 카드 주변 노드 삭제를 없애고 CSS로만 숨깁니다. 카드 제목과 본문만 보이는 형태는 유지합니다.
- 후속 렌더링이 기존 헤더·시간을 참조할 수 있으며, 메시지 루트·내용·링크·리스너·저장된 본문을 보존합니다.
- 메시지 한 개에만 표시 변경을 적용합니다. 잘못된 입력이나 채팅 로그 전체가 전달되면 수정하지 않습니다. 레거시 통합의 DOM 래퍼도 처리합니다.
- 후속 헤더 참조, CSS 표시, 래퍼 입력, 잘못된 루트와 인접 채팅 보존 회귀 검사 3개를 추가했습니다. 전체 자동 테스트는 50개입니다.
- 사용자 환경의 원인을 확정한 실기 검증은 아닙니다. 재현 조건과 한계는 `CHAT-RENDER-FIX.md`에 기록했습니다.

## 0.1.0-alpha.4 · 2026-11-02

채팅에 용어 제목과 설명 블록만 표시합니다.

- 기본 플레이어 채팅 헤더·시간·외부 틀과 여백을 제거했습니다.
- 공유 안내문과 하단 ‘용어 사전 · Term Share’ 문구를 제거했습니다.
- 메시지 작성자·ID·내용 컨테이너를 보존하고 링크 리스너를 재생성하지 않습니다. 메시지 관리는 우클릭 메뉴를 사용합니다.
- 이전 카드도 다시 표시할 때 같은 모양을 적용합니다. 저장된 메시지 본문은 변경하지 않습니다.
- 제목 이스케이프와 단독 카드 구조, 이전 카드/링크/일반 채팅 보존 테스트를 추가했습니다. 전체 자동 테스트는 47개입니다.

## 0.1.0-alpha.3 · 2026-11-02

사전 입력기의 글자 표시와 한글 조합 문제를 수정했습니다.

- 사전 입력기를 브라우저 기본 리치 텍스트 편집으로 교체하고 본문 높이·글자색·배경색·커서색을 명시했습니다.
- 한글 조합 중 본문 재작성·서식 변경·저장·입력기 재생성을 방지합니다.
- 용어명·별칭의 조합도 저장 보호에 포함하고, 직접 누른 저장 버튼은 조합 완료 후 최종 입력을 읽습니다.
- 사전과 채팅의 입력 처리를 분리했습니다. 서식 도구·링크·이미지·색상·실행 취소는 유지합니다.
- 실제 사전 입력기 코드의 조합·표시·붙여넣기·선택 영역·정리 경로와 창 저장 회귀 테스트 9개를 추가했습니다. 전체 자동 테스트는 45개입니다.
- 원인 조사와 미검증 범위를 EDITOR-FIX.md에 기록했습니다. 사전 데이터 형식은 유지합니다.

## 0.1.0-alpha.2 · 2026-11-02

최소 지원 버전을 Foundry V13으로 낮추고 V14 지원을 유지했습니다.

- 설치 manifest의 호환 범위를 V13–V14로 변경했습니다. 실기 검증 전이므로 `verified`는 기재하지 않았습니다.
- V13에서는 `chatMessage` 훅으로 명령어를 처리하고 기존 `MESSAGE_PATTERNS`를 보존합니다. V14에서는 기존 `CHAT_COMMANDS` 등록을 유지합니다.
- 공개 메시지 생성 시 V13의 `rollMode: publicroll`과 V14의 `messageMode: public`을 구분합니다.
- V13 리치 텍스트 편집기에 공개 `save()` 메서드가 없어도 활성 본문을 `value`로 읽어 저장합니다.
- ChatLog의 네임스페이스 내보내기와 전역 내보내기를 모두 처리하고, V13 명령어 패턴의 충돌 감지를 추가했습니다.
- 스타일 manifest를 V13에서도 사용하는 문자열 경로 형식으로 변경했습니다.
- 버전 호환과 V13 흐름 테스트 5개를 추가해 전체 자동 테스트가 36개가 되었습니다.
- 모듈 ID, 설정 키, 사전 형식 버전은 유지합니다. alpha.1의 사전 JSON을 그대로 가져올 수 있습니다.
