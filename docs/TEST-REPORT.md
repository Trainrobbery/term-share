# 알파 검증 결과

버전: **0.1.0-alpha.16**  
작성일: **2026-11-13 (한국 시간)**

## 실행한 검증

alpha.16에서는 Foundry 기본 테마를 추가해 기본값으로 설정하고, 세 테마의 색을 자동완성·사전 관리/편집/가져오기 UI에 연동했습니다. 기존 선택 복원·사용자별 변경, 기본 메시지 틀과 글머리표/번호/중첩 목록의 core 스타일 위임, 다른 테마의 컴팩트 형태 유지, 기존 카드와 DOM/이벤트 보존, 열린 편집기의 한글 조합 보존을 확인했습니다. 추가한 2개 검사를 포함해 전체 68개 테스트를 통과했습니다. core 스타일 위임 검사는 의도적으로 구별되는 모형 CSS와 비교한 계약 검사이며 실제 Foundry CSS를 복제한 검사가 아닙니다. 채팅 전송·IME·자동완성 로직과 사전 편집 스크립트는 alpha.15와 같습니다.

이번 테마의 브라우저 검사는 Chrome의 독립 HTML 표본에서 모듈 CSS와 대표 core 스타일/변수를 함께 적용해 세 테마·밝은/어두운 배경의 계산 색상·기본 틀 위임·목록·입력기 대비를 확인한 것입니다. 실제 Foundry 서버의 화면·게임 시스템·외부 모듈과 OS IME를 실행한 검증은 아닙니다. 아래 alpha.12의 장서 카드 Chrome 표본 기록은 당시 배포의 검사 기록입니다.

alpha.12의 실행 기능 변경은 버전 상수뿐이며 채팅 카드 CSS만 수정했습니다. 메시지 생성·전송, IME·자동완성·사전 편집 스크립트는 alpha.11과 동일하고 개발 의존성도 그대로입니다. 기본 헤더·시간·식별 요소의 안전한 숨김 처리를 유지합니다.

장서 카드 표시는 GitHub Actions의 Chrome에서 모듈의 실제 카드 생성·렌더링 코드와 CSS를 사용한 독립 HTML 표본으로 검사했습니다. 밝은/어두운 배경의 420px 채팅 폭과 220px 좁은 폭에서 지정 색·테두리·간격·서체 크기, 긴 제목·URL·이미지의 폭, 기본 DOM과 기존 카드의 숨김 처리, 일반 채팅 스타일 보존, 링크·우클릭 이벤트 전달을 확인했습니다. 이는 Foundry 본체의 테마 CSS·문서 링크 처리·우클릭 메뉴 구현을 실행한 검증은 아닙니다.

**68개 테스트 통과 / 실패 0개 / 건너뜀 0개.** Node v24.22.1, jsdom 26.1.0, Handlebars 4.7.8에서 `npm test`로 실행했습니다. 채팅 연결 검사에는 ProseMirror 상태 1.4.3, 뷰 1.41.3, 모델 1.25.4와 기본 스키마 1.2.4도 사용했습니다.

alpha.11에서는 조합 중 추천 표시·필터 갱신, DOM 수정 전 compositionupdate, 설정·포커스·일치 여부에 따른 표시, 조합 확정 후 Tab/마우스 완성을 검사했습니다. 새 목록 검사 4개는 수정 전 모두 실패하고 수정 후 통과했습니다. 실제 ProseMirror에서 모델보다 앞선 DOM을 읽는 검사와 조합 중 완성 보호 검사도 2개 추가했습니다. TAP의 실제 브라우저 화면 및 운영체제별 IME 검증은 아직 수행하지 않았습니다. 개발 의존성은 이전 버전과 같으며 모듈 폴더의 npm test로 재실행할 수 있습니다.

## 실제 환경 검증과의 차이

Foundry V13/V14 API는 계약 모형으로 대체했습니다. 사전 입력기 자체는 새 RichTextInput의 실제 코드를 jsdom에서 실행합니다. 서식 명령 실행은 모형으로 검사하므로 실제 브라우저의 execCommand 지원·서식 결과·파일 선택기 흐름까지 확인한 것은 아닙니다. 조합 이벤트는 합성 이벤트이며 OS 키보드 입력이 아닙니다. 표시 회귀 검사는 CSS의 높이와 글자색/배경색 선언을 검사하며 실제 픽셀이나 화면을 검사하지 않습니다.

채팅 연결은 실제 ProseMirror 라이브러리의 EditorView와 EditorState도 실행해 검증했습니다. 실제 Foundry 서버와 그 안의 브라우저 레이아웃, Foundry의 네이티브 ProseMirror 구성, WebSocket 동기화, 운영체제의 IME, GM/플레이어 동시 접속, 외부 모듈 공존은 실행하지 않았습니다. 자동 테스트의 ‘공개 모드’는 생성 데이터와 옵션을 확인한 것이며 실제 두 브라우저의 화면 노출을 확인한 결과가 아닙니다. 사용자 환경에서 `가ㄱ` 현상이 재현·해소됐다고 확정하는 결과도 아닙니다.

용어 블록 단독 표시는 대표적인 채팅 DOM 모형에서 기본 헤더·시간·버튼 및 이전 카드의 헤더·푸터 노드를 보존하고 숨김 클래스를 적용하는지 검사했습니다. 별도 회귀 검사에서는 스타일시트를 실제로 적용해 숨긴 주변 요소의 `display: none`과 카드까지 이어지는 표시 경로, 후속 훅의 헤더·시간 참조, 기존 링크 리스너, 잘못된 루트·인접 메시지 보존을 검사했습니다. alpha.5에서 추가한 회귀 검사 3개는 당시 수정 전 실패하고 수정 후 통과했습니다. alpha.7에서는 공유 안내가 박스 안 제목 바로 위에 위치하고 숨겨지지 않는지, 11px 크기와 문구가 맞는지, 사용자명에 HTML이 들어 있어도 텍스트로 표시되는지, alpha.6의 기존 안내 노드를 안쪽으로 옮기고 반복 적용해도 링크와 노드가 유지되는지를 기존 검사에 반영했습니다. 후속 훅은 독립 DOM 소비자 모형이며 Foundry 내부 구현의 복제나 실제 실행이 아닙니다. 일반 메시지 제외와 이전 저장 HTML 보존도 검사했습니다. 실제 Foundry 테마와 다른 채팅 모듈을 포함한 화면 검증은 아직 수행하지 않았습니다.

실기 검증 전이므로 manifest의 `verified`는 비워 두었습니다. `ALPHA-TEST-CHECKLIST.md`의 항목은 모두 확인 대기입니다.

## 알려진 제약

- 서버에서 저장을 직렬화하거나 버전을 원자적으로 비교하는 장치가 없습니다. 다른 변경을 수신한 오래된 창은 차단하지만 두 GM의 정확히 동시인 저장은 마지막 저장이 우선할 수 있습니다.
- 자동완성은 현재 문서의 기본 채팅 입력을 대상으로 합니다. 다른 브라우저 창으로 분리된 입력 UI는 검증하지 않았습니다.
- 리치 HTML은 허용 목록으로 정리됩니다. 임베드, 비밀 블록, 실행 HTML과 임의 CSS는 보존하지 않습니다.
- 사전 서식 도구는 브라우저 기본 편집 명령을 사용합니다. 지원하지 않는 브라우저에는 안내를 표시합니다.
- 외부 이미지 파일과 링크 대상은 스냅샷에 포함하지 않습니다.
- 외부 모듈이 먼저 이벤트를 가로채거나 모든 채팅 처리를 대체하면 명령어가 실행되지 않을 수 있습니다.
- 1,000개/5 MiB는 입력 제한이며 그 규모의 Foundry 성능 검증 결과가 아닙니다.

## 수정 및 재현

테스트 코드는 패키지의 `tests/`에 포함했습니다. `npm ci && npm test`로 같은 자동 검증을 재현할 수 있습니다. 이 명령은 개발용이며 일반 설치에는 필요하지 않습니다.
