# 실제 Foundry 알파 검증 절차

이 목록은 **수행할 수동 검증**입니다. 현재 실기 완료로 표시된 항목은 없습니다. 첫 확인은 별도 테스트 월드에서 진행합니다. 사전을 만들었다면 변경 전 JSON을 내보냅니다.

## 준비

- [ ] Foundry V13의 정확한 빌드, OS, 브라우저, 게임 시스템과 버전을 기록합니다. V14에서도 아래 항목을 별도로 반복합니다.
- [ ] Term Share만 활성화한 테스트 월드를 준비합니다.
- [ ] GM 브라우저와 플레이어 브라우저(또는 별도 프로필)로 동시에 접속합니다.
- [ ] GM이 예시 사전을 가져옵니다.

## 핵심 흐름

| 확인 | 절차 | 기대 결과 |
|---|---|---|
| [ ] | 플레이어가 `/? 출혈` 전송 | 공개 카드 1개, 원본 명령어 없음, GM에게도 보임 |
| [ ] | `/term Bleeding` 전송 | 정식 명칭 ‘출혈’ 카드 1개 |
| [ ] | `/? 없는단어`, `/?` 전송 | 개인 알림만 표시, 입력 유지 |
| [ ] | 한글 조합 중 `/? 중`까지만 입력 | 추가 공백 없이 일치하는 목록 표시 |
| [ ] | 조합 중 글자 추가·Backspace | 목록이 현재 글자에 맞춰 갱신되고 입력·커서가 유지됨 |
| [ ] | `/? 출` 입력, Tab, Enter | Tab은 완성만, Enter가 공유 |
| [ ] | 한글 조합 중 Tab 또는 추천 항목 클릭 | 마지막 글자 확정 후 완성, 자음 중복·자동 공유 없음 |
| [ ] | `/? 출`에서 Enter만 입력 | 부분 일치로 공유하지 않음 |
| [ ] | ↑↓, Esc, 마우스 선택, 스크롤 | 항목 이동·닫기·완성, 자동 공유 없음 |
| [ ] | 한국어 IME 조합 중 Enter 한 번 | 마지막 글자 확정 후 정확한 용어를 한 번 공유, 불필요한 줄바꿈 없음 |
| [ ] | 조합 확정 직후 즉시 Enter | Tab 선택 없이 정확한 용어 공유 |
| [ ] | 빠르게 Enter 반복 또는 누른 채 유지 | 한 번의 전송에서 중복 카드 없음 |
| [ ] | GM/비공개/자기 자신 모드에서 공유 | 공개 카드로 모든 사용자에게 보임 |
| [ ] | 토큰을 선택한 상태에서 공유 | 용어 블록만 보이고 작성자 메타데이터는 실제 사용자 |
| [ ] | 일반 채팅, 귓속말, `/r 1d20`, Shift+Enter | 기존 기능 정상 |
| [ ] | Enter 직후 입력 수정·붙여넣기·목록 선택·포커스 이동 | 대기 전송 취소, 뒤늦은 자동 공유 없음 |

## 관리와 데이터

- [ ] 플레이어에게 사전 관리 메뉴가 표시되지 않으며 API의 관리 호출도 차단됩니다.
- [ ] GM이 용어를 추가·수정하면 플레이어의 추천 목록과 공유 내용이 갱신됩니다.
- [ ] 리치 텍스트에서 굵게·기울임·밑줄·목록·색상·링크·이미지가 저장 및 재편집됩니다.
- [ ] 사전 입력기의 이미지 도구에서 Foundry 파일 선택이 작동하며 플레이어도 이미지를 볼 수 있습니다.
- [ ] 사전 설명을 모듈 ‘저장’으로 저장하고 다시 열었을 때 서식이 유지됩니다.
- [ ] 밝은/어두운 테마에서 빈 설명 입력란이 충분한 높이로 표시되고 글자·커서가 보입니다.
- [ ] 설명·용어명·별칭에 `가`, `한글 입력`, `가나다`를 입력해 자음이 덧붙지 않는지 확인합니다.
- [ ] 한글 조합 중 Enter, Backspace, 커서 클릭, 서식 도구 클릭, 저장을 시도해 글자가 중복·삭제되지 않는지 확인합니다.
- [ ] 마지막 한글을 입력한 뒤 저장을 한 번 클릭하면 최종 글자가 한 번만 저장됩니다.
- [ ] 새 입력기의 굵게·색상·목록·링크·이미지·실행 취소·다시 실행을 실제 브라우저에서 확인합니다.
- [ ] 명칭·별칭 중복은 차단되고 입력 내용은 유지됩니다.
- [ ] 저장하지 않은 편집 창을 닫을 때 확인하고 취소할 수 있습니다.
- [ ] 용어 삭제는 확인 후 수행되고 기존 카드는 유지됩니다.
- [ ] 새 카드의 박스 안쪽, 제목 바로 위에 `플레이어명님이 다음 지식을 공유했습니다.`가 작게 표시됩니다. 이름은 선택한 토큰명이 아닌 실제 사용자명입니다.
- [ ] 새 카드에는 기본 채팅 헤더·시간·바깥 틀·하단 사전 문구가 표시되지 않습니다.
- [ ] 기존 카드의 저장된 본문 HTML이 유지됩니다. alpha.6 카드의 공유 안내는 다시 표시할 때 박스 안 제목 위로 이동합니다.
- [ ] 용어 블록의 링크 클릭과 메시지 우클릭 메뉴의 GM 삭제가 작동합니다.
- [ ] 용어 카드를 여러 번 공유하고 일반 채팅을 이어서 보내도 모두 표시됩니다. 다시 접속한 뒤에도 카드가 보입니다.
- [ ] 다른 채팅 모듈과 함께 실행하고 시간이 갱신된 뒤에도 콘솔에 헤더·시간 요소의 null 참조 오류가 발생하지 않습니다.
- [ ] 내보내기 → 빈 사전으로 교체 → 재가져오기로 명칭·별칭·서식이 복원됩니다.
- [ ] 잘못된 JSON과 별칭 충돌은 사전 전체를 바꾸지 않습니다.
- [ ] 병합 시 기존 ID가 유지되고 전체 교체 미리보기에 삭제 항목이 나타납니다.
- [ ] 다른 GM의 변경을 수신한 오래된 편집 창은 저장을 차단합니다.
- [ ] 두 GM의 동시에 제출한 저장은 알파의 알려진 제약임을 확인합니다(서버 잠금 없음).

## UI와 공존

- [ ] 채팅 탭 전환, 사이드바 접기, 재렌더링 후 자동완성이 작동하고 팝업이 남지 않습니다.
- [ ] 좁은 채팅 패널, 밝은/어두운 테마, 긴 한글과 이미지에서 내용을 읽을 수 있습니다.
- [ ] 자동완성 끄기와 표시 개수 변경이 개인별로 반영됩니다.
- [ ] 선택된 추천 항목 오른쪽에만 TAP이 흐리게 표시되며, ↑↓로 선택을 옮기면 표시도 함께 이동합니다. 긴 제목·설명과 겹치지 않고 추천 항목 클릭도 정상입니다.
- [ ] `/?`를 끄면 해당 명령어를 가로채지 않고 `/term`은 유지됩니다.
- [ ] Chat Commander와 `/?`를 쓰는 다른 모듈을 하나씩 추가해 충돌 경고와 우회 설정을 확인합니다.
- [ ] 월드 재접속·서버 재시작 후 사전과 개인 설정이 유지됩니다.

## 문제를 기록할 때

Foundry 빌드, 게임 시스템, 활성 모듈, 브라우저/OS, 재현 입력, 예상·실제 결과, 콘솔 오류를 함께 기록합니다. `game.modules.get("term-share").api.diagnostics()` 결과도 도움이 됩니다. 공개 보고에는 비공개 월드 데이터와 개인정보를 제외합니다.
